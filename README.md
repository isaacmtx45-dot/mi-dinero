# Mi dinero

Aplicación personal para calcular cuándo termino de pagar cada meta cuando el
ingreso no es fijo. Funciona sin conexión y **no envía datos a ningún sitio**.

Este repositorio contiene **solo el programa compilado**, que es lo que el
navegador necesita descargar. No hay datos personales ni financieros: todo lo
que se escribe en la app se guarda en el propio aparato.
